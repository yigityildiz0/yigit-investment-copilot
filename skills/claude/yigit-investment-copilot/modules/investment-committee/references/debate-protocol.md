# Debate protocol

## Analyst brief template

```
[ROLE] Fundamental | Technical/flow | News/KAP | Macro/sector
Evidence (with source/time): 3–5 bullets
Direction: + / 0 / −   Strength: 1–3   Evidence quality: A (primary, fresh) / B / C
Flip fact: the one observation that would reverse this view
```

## Bear and bull cases

Each case states: thesis in one sentence; 3 strongest evidence points; quantified scenario (price or return range for the horizon, probability, timing); what the market is missing; kill condition (observable, dated if possible).

Write the bear case first. The bull researcher must answer the bear's two strongest points, and vice versa.

## Rebuttal scoring

For each contested point: `resolved for bull`, `resolved for bear`, or `unresolved (needs X data by date)`. Unresolved points lower confidence and may turn the decision into `İZLE` with a trigger.

## Risk committee

| Member | Posture | Must address |
|---|---|---|
| Aggressive | Maximises expected return within the stated loss budget | Why the upside is worth the volatility |
| Neutral | Balances expected value and drawdown | Base-case sizing and staged entry |
| Conservative | Protects capital | Gap/limit-down loss, liquidity, regime, concentration, correlation with existing holdings |

Each proposes: action · size as % of the loss budget · entry method (limit, staged, breakout confirmation) · stop logic · what would make them change their mind.

## Portfolio-manager decision rules

1. If the bear case has an unrebutted kill condition already triggered → `SAT`/`AKSİYON YOK`.
2. If expected value after costs is not clearly above the cash/deposit alternative for the horizon → `İZLE` or `AKSİYON YOK`.
3. If the regime is a downtrend, cap size at the conservative proposal unless the stock has strong relative strength and an independent catalyst.
4. If evidence quality is mostly C, confidence cannot exceed low.
5. Otherwise choose the neutral size; the aggressive size only for explicitly separated speculative capital.
