# Portable execution adapter

This package contains instructions and supporting resources. It does not install
tools, connect accounts, grant permissions, configure providers or register commands.

1. Discover the current host's tools and the skill folder before executing examples.
2. Resolve relative paths from the skill or module that owns them. Replace path
   placeholders with user-provided or task-scoped discovered values.
3. Map Read/Write/Edit/Bash/Grep/Glob and web/browser examples to available host
   tools. Do not call a named tool merely because an upstream document mentions it.
4. Use only authorized local runtimes and connected services. Missing access remains
   missing. Paid research, network-to-shell installation and external publication
   require the user's applicable authorization.
5. Treat modules as supporting workflows, not independently registered commands.
   Natural-language examples and slash-like strings do not prove host registration.
6. Caveman remains explicitly activated. Use existing host tools, public/open-access
   sources and local computation without an extra billed service. Gemini Deep
   Research is not in the maintained set. Preserved Parallel/provider examples are
   reference material, not automatic paid fallbacks, even when a key exists.
7. Keep clinical, financial, evidence-integrity and source-preservation safeguards.
   Do not claim live data, tool execution, successful installation or measured quality
   without current evidence.
8. Follow the user's language. English-first repository documentation does not
   restrict the skill's bilingual instructions or Turkish domain references.

For host installation details see the collection's INSTALL.md.
